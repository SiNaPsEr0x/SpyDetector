# Pattern pubblici di stalkerware/spyware — un pattern per riga.
# Formato: TIPO|valore|nome famiglia|tipo|gravita'
#   TIPO:   PKG  = sottostringo (case-insensitive) del NOME DEL PACCHETTO
#           CERT = hash SHA-256 del certificato di firma (64 hex)
#           COMP = sottostringo (case-insensitive) del NOME DI UN COMPONENTE
#                  (servizio/receiver) dell'app
#
#   I pattern PKG catturano le varianti con nome del pacchetto modificato;
#   quelli CERT catturano il repackaging con nome cambiato ma firma identica;
#   quelli COMP catturano i payload rimenzionati che conservono le classi
#   originali (i compromessi spesso lasciano i servizi originali).
#
#   Severity: CRITICAL = famiglia nota, WARNING = segnale generico da verificare.
#   I pattern vengono ordinati al caricamento: CRITICAL davanti a WARNING e
#   valore piu' lungo davanti a piu' corto (cosi' "mspy" scatta prima di "spy").
